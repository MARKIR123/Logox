## 目标与边界

在 G:/hz/codes/logox-ts 建立独立 TypeScript 项目，与原 G:/hz/codes/Logox 同级。保留原项目、已有修改和私人运行资料；新实现与新设计落在 TS 项目。

迁移保留 LOGOX 的普通编程助手能力、基于轮次摘要的压缩、Anamnesis 入梦与持久剧团。用户确认的顺序是 **基本功能 → 入梦 → subagent**。已有角色串行派发、独立账本和入梦生命周期接线继续作为基础。

先实现全屏 TUI，采用 React/Ink 和 Node.js；模型、活动、交互与展示数据独立于终端组件，为后续 GUI 保留接口。依赖版本以锁文件为准。未来 Bun 分发与旧 Python 配置/会话的导入方式仍待确定。

| 职责 | 边界 | 专题设计 |
|---|---|---|

| 活动与异步交互 | 运行时拥有状态、请求身份和取消；舞台消费快照 | [运行时与交互](2026-10-11-runtime-interactions.md) |
| 剧团 | 持久角色、串行登场、独立上下文、调度与协作桥 | [持久角色与模型](2026-10-12-persistent-actors.md) |

## 第一阶段：基本功能

先让 Logox 稳定完成日常开发任务，以原 LOGOX 当前指南、模块、源码和测试为行为参考。

| 范围 | 目标 | 当前基础 |
|---|---|---|
| 模型与对话 | 登录、选择、流式回复、重试、取消和错误后继续 | 已有持久 API key、两类协议、统一模型 picker；模型能力和用量展示待补齐 |
| 上下文 | 项目规则、窗口预算、工具归档、随轮摘要、自动/手动压缩和恢复 | 已接入有效视图、轮次摘要、预算、归档、自动整理和 /compact；真实长对话待验收 |
| 会话与回退 | 新会话、历史选择、清空、回退及文件与有效上下文一致恢复 | 已有指定会话/最近会话恢复、write/edit 快照和 /undo |
| 工具与权限 | 原工具行为、权限规则、Shell 审查、只读并发和取消回收 | 基础文件/搜索/Shell、本次审批和进程回收已实现 |
| 配置与扩展 | 分层配置、技能、MCP、自定义命令、重载及已有扩展 | 已有分层 TOML 和命令目录；旧格式兼容与扩展待补齐 |
| 全屏交互 | 长历史、中文输入、缩放、连续回复、审批和正常退出 | 已有实际 Ink 自动回归；真实 Windows Terminal 待现场验收 |

完成条件：连接模型并完成获准工具任务；拒绝、取消或错误后仍可继续；长对话在预算内运行并可恢复；会话与文件回退一致；范围内命令、权限和扩展有实际验收结果。

上下文底座已按[压缩设计](2026-10-12-context-compaction.md)接入，下一项继续完整会话管理和一致回退。基础接口预留角色契约与任务模型，完整角色管理仍在第三阶段接入。

## 第二阶段：入梦
