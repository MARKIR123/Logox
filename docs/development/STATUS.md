会话阅读剩余按[完整链路诊断与修复](designs/2026-10-11-terminal-ui.md#完整滚动链路诊断)在 Windows Terminal 现场验收滚轮/翻页的观感、字体、缩放、底部跟随、悬停、表格窄屏和系统剪贴板。独立会话画布、局部屏幕滚动和表格布局已有模拟终端回归；完整重放不再触发 App/Ink 逐次更新及更新深度警告。
