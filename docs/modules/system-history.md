# 系统历史与环境通知

命令结果、程序错误和环境变更不是助手回复，也不都应该送入模型。本模块把**展示、持久化、模型输入**分开，避免界面通知污染对话或冒充人工授权。

## 保存与展示

系统事件带稳定 ID、时间、类别、会话、角色和可选活动身份。展示位置通过独立的 `presentation` 标注，不按文案关键词或文字长度猜测：

| 展示位置 | 内容与行为 |
|---|---|
| `silent` | 登录取消、未改变内容、模型/思考档位/提供商切换，以及已在当前管理页反映的结果；不额外打印，实际状态仍正常更新 |
| `status` | 设置保存等普通成功回执，仅在当前窗口的现有状态栏短暂提示；连续提示替换同一槽位，不增加时间线行或挤掉 Actor 提示 |
| `panel` | `/skills`、`/models`、`/help`、`/commands` 等查询结果进入只读面板；方向键、翻页键、Home/End、滚轮阅读，Ctrl+C 复制原始全文，Esc 返回并保留草稿和阅读位置 |
| `timeline` | 必要的全局错误、任务进展及其他重要事件；全局错误默认显示独立摘要，可展开详情；带活动身份的任务错误仍关联原任务，不另起故障卡 |
| `welcome` | 仅在没有对话和任务的空白会话中显示欢迎信息，开始任务后消失，不作为时间线消息反复追加 |

局部管理页和登录错误留在当前表单，同时可静默记录事件。系统结果不冒充助手回复，展示仍遵循会话与角色归属。

异步查询先打开临时加载页，加载文本不保存为正式结果；发起时捕获会话、角色与面板 ID，完成后只更新原面板。关闭后迟到成功只保留审计，不重新打开窗口或覆盖新页面；迟到失败保留原角色的可见错误。管理页异步操作同样绑定原面板身份，不能使用后来命令的角色；原页已关闭时，失败回执退回所属角色的全局错误摘要，而不是继续静默。

临时空白会话先缓冲系统事件，首次正式任务登记后保存；正式会话按队列写入，关闭时等待收尾。保存失败保留缓冲并报告，而不是假装已落盘。欢迎信息、复制提示和退出提醒等短暂 UI 状态不都写入历史。

Journal 的会话哈希 `.events.json` 及分支记录用于实际恢复，系统事件不混入 user/assistant/tool 原始模型账本。另有 `sessions/<sessionId>/events.json` 等可读镜像；镜像是便于人工检查的副本，不应当成唯一权威来源。恢复按事件 ID 去重，回退只过滤对应活动，原始记录保留。新事件的展示标注随事件保存；恢复不会重新弹出短提示或自动打开结果面板。没有展示标注的旧记录按原规则兼容，不批量改写或根据英文文案隐藏历史。

## 哪些内容进入模型

| 内容 | 模型如何处理 |
|---|---|
| 普通本地命令结果、页面与命令错误 | 展示/保存，不自动变成模型消息 |
| 模板展开后的任务 | 作为正式任务输入 |
| 工具失败 | 保留与调用配对的 tool result |
| Actor 报告与故障交接 | 按角色来源携带必要状态，不当成人工新增授权 |
| 实际执行环境变化 | 下一次请求按角色补充最新状态 |

执行环境快照包括实际任务模型、思考档位、权限边界、工作目录、scratchpad、规则版本与服务连接；工具/MCP 可用池使用独立能力记录，技能目录仍在 Tools & Skills。EnvironmentState 从有效历史恢复最初基线和最新完整快照，变化在下一次请求追加为带程序来源的 `context` 记录，不修改已有历史之前的 system。准备或取消不会提前消费变化；只打开设置页面或更改选项不会自动启动任务。

故障预算耗尽是当前任务的执行限制，不应伪造成整个工具环境永久消失；下一任务也不应因此收到虚假的“工具恢复”通知。

## 状态栏

应用提供当前窗口的真实状态，TUI 负责布局和裁剪。运行中的 Actor 显示本任务实际模型，空闲时显示其默认选择；排队任务不会遮住正在运行的模型身份。

布局和 motion 偏好主文件为 `~/.logox/statusbar.json`，保留兼容目录读取。保存成功才发布新设置，失败保留旧状态。状态栏字段本身不决定模型上下文、权限或账单。
