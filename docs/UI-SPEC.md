# 当前 TUI 规范

核对日期：2026-10-12。描述当前 React/Ink 全屏界面；验收方法见 [TESTING](development/TESTING.md)，未完成工作见 [STATUS](development/STATUS.md)。设计取舍见[终端舞台](development/designs/2026-10-11-terminal-ui.md)与[slash 交互](development/designs/2026-10-12-slash-interactions.md)，被取代的颜色和布局不作为当前指令。

## 舞台与归属

- 默认使用终端备用屏。舞台、轨道和输入区不设背景色，透出终端背景。
- 顶部没有项目页眉或窗口按钮组；当前窗口与快捷键提示在底部状态区。
- 用户、Logox、角色窗口中的普通正文沿各自轨道展示；轨道与内边距属于装饰，不进入正文复制。
- 主对话中 Director 回复与角色任务卡共用 Logox 轨道，角色卡标题和底色区分角色。明确 @角色的任务与回复按场景的角色归属呈现。
- 窗口切换、卡片折叠、鼠标悬停、草稿和阅读位置属于界面状态。

## 卡片与主题

颜色的代码维护位置是 [cards.tsx](../src/tui/cards.tsx) 的 palette、actorCardPalette，以及 [ensemble.ts](../src/actors/ensemble.ts)/[scene.ts](../src/tui/scene.ts) 当前角色定义。文档说明语义，具体色值以这些定义为准。

- Actor 底色直接使用明亮的绿、蓝、紫红纯色，保留透亮感；标题与选项强调色沿用所属角色色。
- 入梦使用白灰色背景，展开或悬停进一步变亮；标题、正文和状态使用深色文字。白色主题指底色。
- Logox 自己的思考、工具调用没有背景，包括展开正文与悬停。角色内部的工具/思考卡透出所属角色卡底色，不另外混入中性灰。
- 左右各 2 列内边距，窄屏按剩余宽度收缩，正文与任务完整折行。
- 场景中的角色卡用顶部 ▄ 与底部 ▀ 绘制对称的半行留白，标题置于中间；长任务可以占多行。卡片之间的空隙独立于点击和悬停范围。
- 展开态保留顶部细缝、正文分组与底部留白。通用活动组件还显示当前阶段，展开显示细节。
- 鼠标移入有背景的收起卡时使用展开态底色，移出恢复；悬停不展开内容、不改变答案。

角色卡单击折叠，双击进入独立窗口；普通卡单击折叠。完整角色名、任务与状态保持可读，窄屏先显示身份/状态，再换行显示任务。

## 选择与待回答事项

选择统一用 `❯` 和高亮文字。选中项不更换背景，不使用单选圆点；未选中项为标识保留等宽空位。说明另起一行，与标签正文对齐。

许可默认拒绝，只提供本次允许与拒绝。稍后回答保留请求，主输入仍可编辑；Ctrl+X 取消聚焦的请求。Tab 聚焦场景请求时展开并定位对应卡片。界面回答经运行时验证，界面不执行工具。

正式入口将工具审批及多问题内联到所属活动卡片，选项由真实请求生成；自由回答使用原输入编辑器。角色卡在有待回答事项时默认展开，稍后可折叠，Tab 再次展开并定位。

作品集 demo 的许可、偏好、排队和取消来自 RuntimeStore；主窗口与角色窗口回答同一 requestId。脚本 executor 只展示方案和偏好候选，没有实际修改文件。场景数据投影见[模块说明](modules/README.md)。

## 输入、窗口与滚动

主输入从 1 行增长到最多 5 行，超出后只滚动输入视口并跟随光标；矮终端按可用高度缩小。软折行保持原文，中文、组合字和 emoji 按字形编辑。

每个窗口保存独立草稿和阅读锚点。主窗口 @角色是快速指派，不自动进入角色窗口；独立窗口输入默认给当前角色。提交时记录来源窗口和 activityId；排队即可看到任务，轮到角色后才生成回复。

正式舞台的 Assistant 正文呈现 Markdown：标题和强调使用字重，引用用细竖线与斜体，列表保留层级和序号，代码围栏显示语言与铺满正文宽度的上下横线，过长语言标签保持单行并按字形截断；代码与行内代码使用所属轨道色，链接显示名称及地址。表格铺满可用正文宽度，完整显示顶部、表头分隔和底部框线，按列测宽、折行和对齐；列宽不足时纵向显示字段和值，仍保留全宽上下横线。转义竖线和代码内竖线保留为单元格内容。框线随窗口缩放，保留身份轨道和终端安全边距。代码缩进保留，未闭合的流式围栏按代码显示，未闭合行内标记保留文字。主题、卡片留白和选择符号保持原有规则；用户输入和工具原文按字面显示。

显示行映射回原始 Markdown，框选复制保留源标记、链接地址、代码围栏与硬换行，软折行不插入换行。账本和模型上下文继续使用原文。阅读锚点保存消息身份和原文位置，新增分片及缩放后保留所在段落；滚轮或 PageDown 到底部后自动跟随，Ctrl+E 直接恢复底部跟随。同一输入批次的滚轮报告累加处理。全屏会话区域缓存排好样式的行，纯滚动平移已有屏幕并补画新行，输入区和状态栏保持原位；表格整行或整表复制恢复原始 Markdown，单元格选择不包含边框与填充。

| 操作 | 当前键位 |
|---|---|
| 提交草稿或聚焦的回答 | Enter |
| 换行 | Shift+Enter、Alt+Enter、Ctrl+J |
| 命令候选选择；无候选时视觉行上下移动光标 | 输入焦点下 ↑ / ↓ |
| 当前视觉行头尾 | Home / End |
| 草稿头尾 | Ctrl+Home / Ctrl+End |
| 命令候选补齐；无候选时切换输入与问题焦点 | Tab |
| 选择许可或预设答案 | 问题焦点下 ↑ / ↓ |
| 稍后回答；退出自由回答编辑；清除选区；返回主窗口 | Esc，按当前焦点依次处理 |
| 轮换角色窗口 | 正式舞台与 demo 的 Ctrl+G |
| 进入当前选中的角色卡 | Ctrl+Enter |
| 切换卡片 / 展开详情 | Ctrl+N / Ctrl+O |
| 历史翻页 / 回到底部 | PageUp、PageDown / Ctrl+E |
| 取消聚焦请求 / 取消当前角色任务 / 关闭程序 | Ctrl+X / Ctrl+C（空闲时关闭）/ Ctrl+D |

demo 中主草稿为空时 Enter 也会确认当前待回答事项；正式入口使用 Tab 明确聚焦审批或提问。正式舞台与 demo 共用卡片样式，正式消息由 stage.ts 从真实快照生成，未带入作品集样本。具体焦点分支在 [App](../src/tui/app.tsx) 维护。

鼠标滚轮浏览舞台，点击输入区定位光标，拖选正文后通过 OSC 52 复制；标题、轨道、填充与封边不进入复制。运行时启用 SGR 鼠标报告，退出关闭报告并恢复备用屏和输入模式。

## 上下文整理

/compact 复用正式舞台的活动和取消机制，整理当前窗口角色。阶段以“扬弃”呈现，运行时负责预算、归档、汇总和保存；TUI 显示结果与错误，不生成摘要。整理期间禁止新任务或模型切换；Ctrl+C 取消整理，Ctrl+D 等待收尾后退出。/status 显示当前角色最近请求占用、水位及输出额度。

## 维护与验收

改样式时同步本文件的当前规则，历史方案留在设计；改变提交、取消、请求生命周期或窗口路由时先确认产品行为并写设计。

自动检查覆盖实际 Ink 的模拟 TTY 接线；字体、透明度、中文输入法和系统剪贴板按真实 Windows Terminal 验收。颜色输出和真实终端观感分别记录。

## 提供商登录

正式舞台输入 /login 时，登录区临时替换普通输入区，上方对话仍可阅读；/login 名称直接进入该提供商 API key 输入。列表按方向键选择，只有标识 ❯ 和文字使用现有 accent 高亮，不改变选中行背景。

密钥使用独立遮罩编辑器，支持输入、粘贴、左右/Home/End、删除和 Ctrl+U 清空。Enter 保存；保存中不重复提交，失败留在登录区。Esc/Ctrl+C 取消尚未提交的输入，Ctrl+D 关闭；保存或取消恢复原对话草稿。密钥不进入主草稿、交互回答、复制内容、消息或历史。TUI 不拥有认证持久化，只调用 LoginFlow。

## 命令联想

正式舞台输入 / 显示当前支持的命令和中文用途，最多五行，方向键选择时列表跟随；矮屏按可用空间缩小。候选在输入区上方，选中项仅使用 LOGOX accent 和 ❯，不改变背景。命令与公开候选见 [commands.ts](../src/commands.ts)，替换逻辑见 [completion.ts](../src/tui/completion.ts)，呈现见 [command-menu.tsx](../src/tui/command-menu.tsx)。

Tab 补齐但不执行；Enter 确认可无参数执行的命令并执行，必填参数的命令先补齐。/model 与 /provider 无参数打开选择器，Tab 仍可补齐成带参数的输入。提供商/模型参数 Enter 只补齐，再按 Enter 提交。Esc 关闭菜单保留草稿，输入或光标位置改变后重新联想；Shift/Alt+Enter 保持换行。候选可见时优先处理选择键，没有候选时保留审批聚焦与原编辑行为。登录密钥、自由回答、多行文本及正文中间的 / 不联想。

application 提供可用提供商名称、当前提供商的已查询模型及目录中的“提供商/模型”候选；界面不读认证、不在键入时查询模型。App 的普通卡片高度在提交布局后测量，相同高度不调用状态 setter；正式舞台没有普通卡片测量节点时保持零值，避免流式更新触发重复测量渲染。

## Slash 选择器与页签页面

[CommandPane](../src/tui/command-pane.tsx) 统一细分隔线、左右留白、固定高度与底部提示；[Picker](../src/tui/picker.tsx) 和 [TabbedPage](../src/tui/tabbed-page.tsx) 共享这个容器。标题、说明、选项/页签、当前项、空状态和完成回调由调用方提供。继续使用 LOGOX 的绿色 accent 与 ❯，没有选中背景。

/model 打开模型选择器，/provider 与 /providers 打开提供商选择器；/login 的提供商阶段也使用 Picker。选择器临时替换输入区，上方保留舞台。键入或粘贴筛选公开候选，Ctrl+U 清空筛选；↑↓、Home/End、PageUp/PageDown 导航，Enter 确认，Esc/Ctrl+C 取消。模型右侧保留提供商名称，避免同名模型混淆。加载、空列表、部分查询失败和确认失败显示在当前界面；确认成功才应用选择。

/status、/config、/help 打开同一个全屏页签页面，分别定位“状态”“配置”“命令”。←→、Tab/Shift+Tab 切换页签；↑↓、PageUp/PageDown、Home/End 浏览内容，各页签分别保留滚动位置。窄屏优先显示当前页签。配置页展示真实生效值，修改其他配置仍通过 config.toml 后重启。

命令界面打开期间拥有键盘焦点，输入不流入主草稿或审批。Esc/Ctrl+C 返回原角色窗口、草稿、阅读位置与审批焦点；Ctrl+D 关闭应用并中止目录查询。取消不改变模型、不调用模型、不写模型账本。命令状态由 [CommandSurfaces](../src/commands/surfaces.ts) 管理，查询身份和取消信号防止旧响应重新打开界面。
