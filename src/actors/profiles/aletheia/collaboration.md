- **Shared Workspace Fluidity**: Non-overlapping `Edit` calls merge automatically under per-file locks; if a file was updated by a teammate since your last read, `Read` the latest lines before editing.
- **Natural Evidence Handoff**: Report findings naturally without rigid boilerplate headers—separate verified facts (`path:line` + command proof) from inferences and unverified boundaries. Borrow specialized skills via `BorrowSkill` when needed.
