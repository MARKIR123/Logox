# Weather Card

Build a standalone `index.html` weather card using `data/weather.json`.

## Requirements

- Single self-contained `index.html` file with inline CSS and inline SVG graphics.
- Zero external requests or external assets (works offline via `file://`).
- Display the city name, current temperature, a custom SVG icon matching the current condition (`sunny`, `cloudy`, or `rainy`), and a single row below showing the 3-day forecast.
- Draw weather icons using SVG primitives; do not use weather emoji characters.
